## מגבלות (סעיף 17)
Android עשוי להגביל שירותי רקע. נגישות אינה מבטיחה חסימה בכל מסלול. תמיכת הגבלות Device Owner תלויה ביצרן. זיהוי וידאו אינו מוחלט.

- כלל מותאם חדש: כבוי (VideoStop כבוי כברירת מחדל).
