## מגבלות שיש להציג

Accessibility לא מבטיח חסימה בכל מסלול. מניעת שינוי שעון מלא דורשת Device Owner. שעון שהוזז **קדימה** מעבר לאתחול אינו ניתן לזיהוי בלי Device Owner. זיהוי וידאו אינו מוחלט. כל מה שתלוי ביצרן, ב‑Device Owner או בהרשאות בפועל **דורש BF88**.

## ברירות מחדל שהוחלט עליהן בהיעדר החלטה (הפיכות, ניתנות לשינוי בהגדרות)

- הדלקת נרות 18 דקות לפני השקיעה, בלי מרווח נוסף. סיום החסימה לפי 8.5 מעלות. יום טוב שני בישראל כבוי כברירת מחדל.
- קבוצות: אפליקציה בקבוצה אחת לכל היותר. הפסקה מתוזמנת משהה את המכסה, ולא את שאר מקורות החסימה.
- חלון שוויון שעות (התחלה = סיום) הוא ריק. יממה שלמה היא 0 עד 1440.
- חריג חוסם מנצח חריג מתיר כשהם חופפים.
- שחזור שאינו מאפס יומן או שימוש. מפתחות סוד, מונים וחלונות זמן לא נכללים בגיבוי.
- לוח השנה חישובי, לכן אין "התיישנות" נתונים. נדרש רק מיקום תקין.

## מה נותר (לפי סדר חשיבות)

1. אחסון: שמירת מכסות, קבוצות, לוחות, יומן, מצב `TrustedClock` ב‑`Store`.

3. שבת/חג: מיקום, מתזמן, התראה, בדיקה לפני כניסה, מצב קריאה בלבד, אתחול באמצע שבת.
4. מסכים: ניווט הניתן לבחירה, חסימות ב‑3 לשוניות, מסכי מכסות/לוחות/שבת/יומן/גיבוי, חיווי הצלחה ושגיאה.
5. VideoStop, גילוי התקנה/הסרה, מאזין אתחול, גיבוי אוטומטי.
6. סקירת שינויי `Policy` של ChatGPT, ובדיקת מסלול השחרור לפני כל דבר במצב חזק.
