# מגן · Magen

אפליקציית אנדרואיד (Kotlin + Jetpack Compose, עברית ואנגלית) לנעילת אפליקציות, חסימת התקנות והגנה מהסרה.

## בנייה ב-GitHub (מומלץ, עובד גם מהטלפון)
1. צרו מאגר (Repository) חדש.
2. **Add file → Upload files** והעלו את `Magen.zip` כמו שהוא (בלי לפרק).
3. **Add file → Create new file**, בשם `.github/workflows/build.yml`, והדביקו את תוכן הקובץ `build.yml` שצורף. (בהעלאת תיקייה מלאה מהמחשב הקובץ כבר במקום.)
4. לשונית **Actions → Build APK → Run workflow**. אחרי כ-5–8 דקות נכנסים להרצה הירוקה ובתחתית העמוד, תחת **Artifacts**, מורידים `magen-debug-apk`.
5. מחלצים את ה-APK מקובץ ה-zip שמורד ומתקינים בטלפון.

אם בריפו יש קבצי workflow אחרים (למשל תבנית שנוצרה אוטומטית), מחקו אותם כדי שלא ירוצו במקביל.

## בנייה ב-Android Studio
File → Open על התיקייה, המתנה ל-Sync, ואז Run.

## מה נבדק בפתיחה
בפתיחה הראשונה: ברוכים הבאים ← בחירת רמת הגנה (רגילה/חזקה) ← יצירת קוד ← אשף הרשאות (נגישות, מנהל מכשיר, ובחזקה גם Device Owner). האשף חוזר בכל פתיחה כל עוד חסרה הרשאה (אפשר לדלג).

## רמות הגנה
ראו את ההשוואה בלשונית "עוד" ובמדריך שבאפליקציה. מצב חזק מוגדר פעם אחת ממחשב:
`adb shell dpm set-device-owner app.magen.lock/.AdminReceiver`

## חסימת חלקים בהגדרות
יותר מ-50 דפים מוכנים, בחמש קבוצות. החסימה תלויה בכותרות שהיצרן והשפה קובעים. אפשר להוסיף דף ידנית (גם כנתיב `רשת ואינטרנט > אינטרנט`, נשמר החלק האחרון). ההסבר המלא בלשונית "חוקים".

## אם הבנייה נכשלת
בדף ההרצה ב-Actions, בראש העמוד, מופיע הסעיף **Build errors** עם השורות הרלוונטיות, ובתחתית יש artifact בשם `build-log`.

## מגבלות
- חסימות מבוססות נגישות הן "מאמץ מיטבי": מגיבות אחרי שהמסך נפתח, ותלויות בטקסטים של המערכת.
- חסימת דף הגדרות בודד נעשית לפי כותרתו. יש כמה קטגוריות מובנות, ואפשר להוסיף כותרת חופשית.
